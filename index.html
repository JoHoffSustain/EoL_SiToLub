SiToLub LCA tools

Interactive tools behind the life cycle assessment in SiToLub (deliverable D5.1). They cover how lubricant performance enters the functional unit and what happens to the lubricant at the end of its life.

Functional unit and use phase

questionnaireFU QuestionnaireAnswer a few questions on scope, application and use pattern. You get the functional unit, the reference flow, the openLCA parameters and text for the report. explorerFU ExplorerFormulas for all lubricant classes and all five scopes, the applied system examples (car, machining, deep drawing) and the parameter map. mapFull Life Cycle MapUse case → module → database flow, and the exchange threshold for corrosion protection.

End of life

fateFate ExplorerSankey of 1 kg lubricant put on the market: use losses, collection and end-of-life routes by application, class and formulation.

Data and models

  • FU matrix (Excel): functional units, reference flows and formulas per lubricant class
  • MWF additive example (Excel): one additive taken through all five scopes
  • openLCA parameters and formulas for the parametrised ecoinvent processes (the JSON-LD itself is not published, as it contains licensed ecoinvent data)
